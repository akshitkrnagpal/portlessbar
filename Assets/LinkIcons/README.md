# Link icons

- GitHub Invertocat: unmodified black SVG/PDF from [GitHub’s official brand toolkit](https://brand.github.com/foundations/logo) ([download](https://brand.github.com/GitHub_Logos.zip)).
- X: unmodified SVG from the [official X brand toolkit](https://about.x.com/en/who-we-are/brand-toolkit?web=1) ([download](https://about.x.com/content/dam/about-twitter/x/brand-toolkit/x-logo.zip)); PDF generated with `rsvg-convert -f pdf XMark.svg -o XMark.pdf`.

The marks identify their respective link destinations and remain the property of GitHub and X. Bundled PDF assets are rendered as monochrome templates to follow the system appearance.
