# Branding

PortlessBar uses white Menlo monospace lettering on black. The full app identity is `portlessbar`; the square app icon and menu bar status item use the compact `p_` terminal mark.

The app icon has a full square background and sharp corners without a baked-in mask, gradients, or shadows. The outlined SVG assets do not depend on installed fonts.

Run `./scripts/render-logo.sh` on macOS to regenerate the committed app icon and wordmark assets. App builds generate the ICNS sizes from the PNG.
